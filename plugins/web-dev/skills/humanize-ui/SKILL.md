# Humanize UI

AI sites look generic. Establish trust -> need custom vibe. AI scaffolds fast -> humans make bespoke.

## Guidelines

### 1. Kill "AI-Speak" Copy
AI uses vague fluff.
- **Kill buzzwords**: Delete `seamless`, `elevate`, `delve`, `revolutionize`, `robust`, `dynamic`, `synergies`.
- **Write how speak**: State exact function. "Manage roster" > "Elevating digital community management seamlessly".
- **Vary sentence length**: AI uses equal length sentences. Break up. Short, punchy.

### 2. Ditch "Plastic" Imagery
Hyper-glossy cyborgs scream AI.
- **Use real UI**: Show actual interface. Unpolished real > fake AI.
- **Refine AI assets**: Don't drop raw output. Edit: flatten colors, remove "Midjourney sheen", match palette.
- **Use SVGs**: Clean vector icons > complex AI raster images.

### 3. Break Predictable Grid
AI defaults to: big hero -> 3 columns -> zig-zag text/image.
- **Asymmetry**: Don't center all. Left-align headers. Use 60/40 split. Break containers.
- **Whitespace**: AI spaces uniformly. Adjust padding/margins. Add breathing room.

### 4. Elevate Typography and Color
AI defaults to boring fonts (Bootstrap/Tailwind).
- **Swap fonts**: Ditch Inter, Roboto. Pair strong serif (Playfair) header + clean sans-serif body.
- **Ground color**: Avoid neon/sterile blue. Pick 1 primary brand color for CTA. Use off-whites/dark grays.

### 5. Add Micro-interactions
AI misses subtle human details.
- **Hover states**: Button smooth color change/lift on hover.
- **Subtle transitions**: 0.2s ease on links/interactive elements.
